## 11. Technical Debt Findings

### A. Soft-Delete Utilities — **REMOVED**
- **Files Removed:** `packages/db/src/utils/soft-delete.ts`
- **Files Modified:** `packages/db/src/index.ts` (removed export), `packages/db/tests/repositories.test.ts` (removed 2 tests)
- **Reason:** Utilities referenced `deletedAt` field which does not exist in Prisma schema. Models use `isActive: Boolean` (Company only). Utilities were exported but unused in repository code — only tested. Misleading and incorrect.
- **Impact:** db test count reduced from 8 → 6 (2 soft-delete utility tests removed). No functional regression.

- Must be addressed at infrastructure layer before production (Blocker B-03)
